# Minimi Search

**Retrieve the conversation before researching the change.** Each completed turn is stored in SQLite with the user's question, the assistant's answer, source annotations, UTC timestamp and the browser's local calendar day. On each request, the server builds a bounded context from exact-date matches, recent turns in the current chat and, for recall prompts, stemmed full-text matches across that browser's chats. Exact dates lead because “what did I ask on 3 November?” may share zero words with the original question. The model gets the candidate turns and can ask for clarification if several fit. Old answers are historical records with fallible claims.

**Use one model request and one tool.** Node sends the context and question to Groq with one function tool backed by Tavily Search. OpenAI Responses is a configurable alternative. Pure recall and casual chat can skip search. For a change check, the model recovers the entities and baseline date, then searches vendor pricing and dated announcements. Its instructions require comparable tiers, regions and billing terms, and distinguish confirmed changes, today's facts and gaps in coverage. A current pricing page can support a current price, but the date of a change needs dated evidence. The server gives each Tavily result an ID and maps cited IDs to the original result URLs. Uncited search results can appear as sources retrieved. OpenAI supplies citation annotations that the browser places at their offsets. The browser sanitizes the rendered Markdown.

**Keep the fast path short.** Retrieval is local and avoids a separate routing call. The app emits status updates immediately. Groq searches in parallel within each of two tool rounds, with up to eight distinct queries. OpenAI streams search progress and answer text. Both paths have a deadline and a tool-call cap. SQLite persists a turn only after provider completion. Server logs record response timing without logging transcript content.

**Tradeoffs.** I chose exact dates plus SQLite full-text search over embeddings or rolling summaries. This preserves wording and dates for precise recall with no extra service. Paraphrases without shared terms can still miss. I use hosted search to avoid maintaining a crawler. Tavily returns URLs directly, so citation rendering does not depend on the model reproducing links. Search ranking still depends on the provider. Search instructions steer the model away from private terms, but they are not a data-loss prevention boundary.

**With another week**, I'd build a labeled evaluation set with distractor chats, archived pricing evidence and ambiguous dates. I'd measure recall accuracy, shortlist coverage, citation entailment, unsupported change claims, and p50/p95 latency. The first experiments would compare hybrid lexical and semantic recall and test whether per-vendor parallel search improves five-item coverage enough to justify the additional orchestration.
